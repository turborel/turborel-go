# Installing

[Contents](README.md)

This chapter will tell what the driver needs, Go 1.26 or later on Linux,
macOS or Windows, and how it is added to a program's module with
`go get`. No release is published yet: until one is, the driver is built
from its source, as the repository's [README](../../README.md) says. The
chapter is written with the standard API, milestone M7.
